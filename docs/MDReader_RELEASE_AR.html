تثبيت MDReader على Windows

حزمة اختبار x64 — الإصدار 1.0.1.0

المحتويات

  • MDReader-x64.msix — التطبيق.
  • AppPublisher.cer — الشهادة العامة فقط.
  • Install-MDReader.ps1 — تثبيت اختياري يطلب موافقتك قبل إضافة شهادة الاختبار، ثم يثبت الحزمة ويصنع اختصار سطح مكتب.
  • لا يوجد PFX أو مفتاح خاص أو كلمة مرور في ZIP.

خطوات التثبيت

  1. فك ZIP إلى مجلد.
  2. افتح PowerShell كمسؤول في ذلك المجلد.
  3. نفّذ:
Set-ExecutionPolicy -Scope Process Bypass
.\Install-MDReader.ps1

تحقق من بصمة الشهادة قبل الموافقة. بديل يدوي بعد توثيق الشهادة في Trusted People:

Add-AppxPackage -Path .\MDReader-x64.msix

لا تضف شهادة إلى مخزن الثقة إلا إذا كنت تثق بمصدر الحزمة. التثبيت الذاتي التجريبي لا يعني أن Windows سيثق بها تلقائيًا على أجهزة الآخرين.

سبب 0x800B0109

Windows لا يثق بشهادة توقيع الحزمة الذاتية قبل توثيقها. للتجربة المحلية اتبع سكربت التثبيت بعد مراجعة البصمة. لا تستخدم هذه الشهادة للتوزيع العام.

اختيار شهادة للنشر

  • جهازك أو مجموعة اختبار صغيرة: شهادة ذاتية، ويجب توثيق الثقة على كل جهاز.
  • مؤسسة: شهادة المؤسسة المنشورة على الأجهزة المدارة.
  • Microsoft Store: لا تحتاج شهادة توقيع خاصة؛ المتجر يوقّع MSIX بعد قبول التطبيق.
  • تحميل مباشر للجمهور: شهادة توقيع موثوقة عامة أو خدمة توقيع إنتاجية.

لا تغيّر Publisher في manifest من تلقاء نفسك، فمطابقته لهوية الشهادة ضرورية وقد يؤدي تغييرها إلى منع تحديث الحزمة الحالية. لا ترفع ملف PFX إلى GitHub أو ZIP.

تعليمات Microsoft Store · دليل توقيع MSIX.

الإزالة

Get-AppxPackage -Name "MDReader.MDReader" | Remove-AppxPackage

احذف شهادة الاختبار من Trusted People فقط بعد التأكد من بصمتها؛ لا تحذف شهادات أخرى.

حالة النشر

هذه حزمة اختبار غير منشورة. لم يتم إرسالها إلى Microsoft Store أو موقع عام. يلزم مراجعة تحذيرات Release، اختبار التثبيت والتحديث والإزالة، وتجهيز صفحة المنتج قبل نشرها.
