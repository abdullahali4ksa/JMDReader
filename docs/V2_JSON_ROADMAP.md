تحويل MDReader من مجرد قارئ ومحرر ماركداون إلى **قارئ مستندات وبيانات تقنية متكامل (Technical Document & Data Reader)** عبر إضافة دعم كامل وعالي الأداء لملفات JSON مع عرض شجري تفاعلي بالألوان، والطي والفرد، والبحث، والتحميل.

## 📋 مصفوفة مهام الإصدار الثاني (Phase 22 Tasks)

### 1. [P22-T001] محرك تحليل وتحقق JSON فائق السرعة (Core JSON Parser & Validator)
* استخدام `System.Text.Json` مع دعم الـ DOM فائق السرعة (`JsonDocument` و `Utf8JsonReader`).
* تدقيق الأخطاء النحوية فورياً (Syntax Error Linting) وتحديد السطر ورقم الحرف بدقة عند وجود خطأ في ملف الـ JSON.
* دعم ملفات JSON الضخمة (>50 ميجابايت) عبر القراءة الانسيابية دون تجميد واجهة المستخدم.

### 2. [P22-T002] عارض الشجرة التفاعلي الملون (Interactive Colored JSON Tree View)
* تمييز لوني دقيق ومتناسق مع الثيم (الأبيض والداكن والسيبيا):
  * **المفاتيح (Keys):** لون أزرق نقي `#0969DA` (فاتح) / `#79C0FF` (داكن).
  * **النصوص (Strings):** لون أخضر زمردي `#0A8543` / `#7EE787`.
  * **الأرقام (Numbers):** لون برتقالي `#953800` / `#FFA657`.
  * **القيم المنطقية (Booleans & Null):** لون بنفسجي ملكي `#8250DF` / `#D2A8FF`.
* أيقونات نوع البيانات لكل عقدة: `{}` للكائنات، `[]` للمصفوفات، `T` للنصوص، `#` للأرقام.
* أسهم طي وفرد تفاعلية (Expand / Collapse) لكل مستوى شجري مع إحصائية عدد العناصر (مثل: `[12 items]` أو `{5 keys}`).
* زر "توسيع الكل" (Expand All) وزر "طي الكل" (Collapse All).

### 3. [P22-T003] محرك البحث ومسارات JSONPath (Search & JSONPath Query)
* البحث الفوري في المفاتيح والقيم مع تظليل النتائج المطابقة.
* شريط استعلام JSONPath (مثل: `$.store.book[*].author` أو `$.users[0].id`).
* إمكانية النقر بالزر الأيمن على أي عقدة لنسخ مسارها فورياً: `Copy JSONPath` و `Copy Key` و `Copy Value`.

### 4. [P22-T004] أدوات التنسيق والضغط (Beautify & Minify)
* زر تنسيق وتجميل الكود بنقرة واحدة (Format / Pretty Print) مع اختيار المسافات (2 أو 4 مسافات).
* زر ضغط وإزالة المسافات (Minify / Compact) لتجهيز الملف للنقل أو الاستخدام البرمجي.
* تحويل JSON إلى جدول مصفوفات متناسق (JSON Table View) للبيانات الجدولية.

### 5. [P22-T005] تصدير وتنزيل الشجرة (Export & Download Tree)
* زر تنزيل الملف المنسق بنقرة واحدة (`Download JSON`).
* إمكانية تصدير شجرة الـ JSON كملف HTML مستقل يعمل بدون إنترنت مع الاحتفاظ بالألوان وقابلية الطي.
* إمكانية تحويل كائنات JSON إلى جدول ماركداون (Convert JSON to Markdown Table) بنقرة زر.

### 6. [P22-T006] تكامل التبويبات والتعرف التلقائي (Multi-Format Workspace Integration)
* دعم فتح ملفات `.json` و `.jsonc` و `.jsonl` جنباً إلى جنب مع ملفات `.md` داخل نفس التبويبات.
* التبديل التلقائي للشريط العلوي ليعرض أدوات JSON عندما يكون الملف المفتوح JSON، ويعرض أدوات الماركداون عندما يكون الملف ماركداون.

## 📚 قائمة الصيغ والنصوص المقترحة للمستقبل (Supported Formats Roadmap)

| الصيغة | الامتداد | الغرض ومجال الاستخدام |
| :--- | :---: | :--- |
| **Markdown** | `.md`, `.markdown` | التوثيق، المقالات، والملاحظات (مدعوم حالياً بالكامل) |
| **JSON** | `.json`, `.json5`, `.jsonl` | تبادل البيانات وواجهات برمجة التطبيقات (الإصدار الثاني v2.0) |
| **YAML** | `.yaml`, `.yml` | إعدادات Docker, Kubernetes, CI/CD Pipelines |
| **CSV / TSV** | `.csv`, `.tsv` | الجداول والبيانات المالية والإحصائية مع عارض فرز تفاعلي |
| **XML** | `.xml`, `.svg` | المستندات الهيكلية ورسوم SVG المتجهة |
| **TOML** | `.toml` | ملفات إعدادات المشاريع الحديثة (Python, Rust) |
| **EPUB** | `.epub` | قراءة الكتب الإلكترونية والروايات بنمط قراءة الكتب |
| **PlainText & Logs** | `.txt`, `.log` | ملفات السجلات والملاحظات السريعة مع البحث السريع |
