### Description
```markdown
JMDReader is a modern, ultra-fast Markdown document reader and editor built natively for Windows 10 & 11 using the Windows App SDK (WinUI 3).

Designed for technical writers, software engineers, researchers, and students, JMDReader combines an elegant, distraction-free reading experience with powerful editing capabilities, fluid auto-scrolling, and rich mathematical and diagrammatic rendering.

🌟 KEY FEATURES:
• Distraction-Free Reading Mode: Clean full-width typography optimized for reading long-form technical documentation, research papers, and books without distractions.
• Teleprompter Smooth Auto-Scroll: Continuous subpixel scrolling for hands-free reading, speech delivery, and presentations. Choose from presets (1x, 2x, 3x, 4x, 5x) or set your own custom speed.
• High-Fidelity Rendering:
  - GitHub-Flavored Markdown (GFM) tables with sortable layout.
  - KaTeX mathematical expressions and LaTeX formula rendering.
  - Mermaid diagram compilation (flowcharts, sequence diagrams, class diagrams).
  - GitHub callout alerts (Note, Tip, Important, Warning, Caution).
  - Interactive task lists and syntax-highlighted code blocks.
• Instant Standalone HTML Export: Export any document into a 100% self-contained, offline-ready HTML file with bundled styles, mathematical fonts, and interactive features.
• Native Dual-Theme Support: Thoughtfully designed Light and Dark modes with high-contrast text controls.
• Multilingual Support: Switch effortlessly between 10 world languages with instant RTL (Right-to-Left) layout support for Arabic.
• Interactive Table of Contents: Fast heading navigation tree with active scroll synchronization.
• Notes & Highlights Drawer: Bookmark and annotate key excerpts directly alongside your documents.
• 100% Private & Offline: Zero tracking, zero telemetry, zero accounts. All files stay strictly on your local machine.
```
